## Directory map
```
src/
├── routes/          ← Fastify route handlers, one file per resource
├── services/        ← Business logic; called by routes, call repositories
├── repositories/    ← Prisma queries; only layer that touches the DB
├── middleware/      ← auth.ts, rateLimit.ts, requestId.ts
├── workers/         ← BullMQ job processors (email, notifications)
├── lib/
│   ├── s3.ts        ← S3 presigned upload wrapper
│   ├── queue.ts     ← BullMQ client and queue definitions
│   └── prisma.ts    ← Prisma client singleton
├── types/           ← Shared TypeScript interfaces and Zod schemas
└── index.ts         ← App entry point, plugin registration

prisma/
├── schema.prisma    ← Source of truth for DB schema
└── migrations/      ← Auto-generated, never edit manually

infra/               ← Terraform (ECS, RDS, S3, Secrets Manager)
```

## Finding things
| Task | File |
|------|------|
| Add a route | `src/routes/<resource>.ts` → register in `src/index.ts` |
| Add business logic | `src/services/<resource>.service.ts` |
| Add a DB query | `src/repositories/<resource>.repository.ts` |
| Change the schema | `prisma/schema.prisma` → `npx prisma migrate dev` |
| Add a background job | `src/workers/<job>.worker.ts` + queue definition in `src/lib/queue.ts` |
| Change auth behavior | `src/middleware/auth.ts` |

## Generated / do not edit
- `prisma/migrations/` — generated by `prisma migrate dev`
- `node_modules/`
- `dist/` — compiled output
- `prisma/client/` — generated Prisma client
